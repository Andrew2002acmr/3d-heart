# Multiclass Feature Lab — Stage 04

Запуск существующего CT Preprocessing Lab: `.venv/Scripts/python.exe -m ct_lab.multiclass_launch` из `repository`, http://127.0.0.1:8510 → Multiclass Feature Lab. В Learnable Feature Explorer также есть переключатель Binary / Multiclass. GUI не обучает модели автоматически; кнопка dense inference применяет уже обученную MLP в фиксированной GT-free ROI.

Последовательность: `multiclass_train` (freeze, data, 36 main + 6 internal CV encoders), `multiclass_analysis` (heldout source CT transformations, natural-distribution evaluation, correlations/permutation), `multiclass_dense` (ROI и полное ct_1001, immutable CHD68 v1/v2 comparison), `multiclass_projection`, `multiclass_verify_ui`, `multiclass_report`. Каждый модуль запускается через `.venv/Scripts/python.exe -m ct_lab.<name>`.

Все параметры до первых validation results: `../outputs/multiclass_feature_04/protocol.json`. Существующие receipts/data reuse; для полного воспроизведения — отдельная копия проекта, не удалять старые эксперименты. CPU-only для feature extraction/MLP, CHD68 использует CUDA при наличии или CPU; production training tests не запускать для проверки этой лаборатории.

Raw labels вне 0–7 → ignore255. Validation spatial IDs выбираются без GT; train sampling использует masks только как targets/strata. Full-volume/ROI inference не принимает mask. Источник неизвестен как HU; неизвестные header units не называются миллиметрами. CT perturbations — mild synthetic recipes, не реальные scanner domains. Результаты reused development validation не независимая/клиническая оценка.

Dense probabilities: `dense/**/probabilities.npy`, `dense_full/**/probabilities.npy`, float16 XY Z C (8 channels); final uint8 mask computed before storage rounding. `prediction.npy/.nii.gz`, `entropy.npy`, `metrics.json`, `components.json` сохраняются рядом. Компактный ZIP исключает большие dense `.npy` и повторяющиеся model `predictions.npz`/`robust_*.npz`; все они остаются в outputs. Checkpoints, входные feature caches, NIfTI predictions, метрики, проекции и код входят в ZIP. Все component sizes сохранены; 3D UI отображает точки крупнейших компонент с корректными полными counts. HD95 только в index units; ROI edge/ignore adjacent surfaces censored. Точный HD95 вычисляется KD-tree на небольших ROI и raster EDT на больших массивах, оба метода проверены на совпадение.

Report: `../MULTICLASS_FEATURE_EXPERIMENT_04.md`. Tests: `tests/test_multiclass_lab.py` + прежние inference/filtering/spatial/encoder tests. Browser: `node ct_lab/multiclass_browser.cjs`, isolated temporary headless Chrome, existing Playwright from web/node_modules. Исходные CT/маски, frozen split/preprocessing и CHD68 checkpoint hashes проверяются в конце, все прежние outputs сохраняются.
