# ImageCHD: первый прототип реконструкции сердца

Рабочая цепочка: **NIfTI КТ + готовая маска → проверка геометрии → срезы → отдельные mesh → интерактивный PyVista viewer**.

Реальный пример `ct_1001` скачан и обработан. Обучения сегментации, гемодинамики, веб-сервера и отдельного приложения здесь нет.

**Ограничение данных:** в `ct_1001` spacing заголовка равен `1 × 1 × 1`, единицы неизвестны. Геометрия КТ и маски совпадает, но реальный физический масштаб и анатомическая ориентация ещё не подтверждены. Viewer показывает геометрию NIfTI, а не проверенную модель в миллиметрах. Подробности — [отчёт первого этапа](first_run.md).

## Запуск viewer после построения

В PowerShell из корня проекта:

```powershell
.\.venv\Scripts\python.exe -m heart3d view outputs\ct_1001_v1
```

Или `powershell -ExecutionPolicy Bypass -File .\run_viewer.ps1` (параметр действует только для запуска этого скрипта).

Управление: левая кнопка мыши — вращение, колесо — масштаб, средняя кнопка — перемещение. Флажки или клавиши `1`–`7` включают и выключают структуры. `r` сбрасывает камеру, `q` закрывает окно. Миокард закрывает часть камер: отключите `MYO`, чтобы рассмотреть их. Непрозрачность и полное разрешение сохранены по умолчанию.

Окно native VTK/PyVista открывается отдельно. В браузере ничего запускать не нужно. PNG-превью — статическое изображение; интерактивность доступна по команде выше.

## Структура

```text
heart3d/
  volume.py       # чтение NIfTI, геометрия, список пар
  labels.py       # анатомические ID и единые цвета
  slices.py       # 9 срезов с маской
  surfaces.py     # marching cubes, координаты, VTP, диагностика
  viewer.py       # камера и переключатели видимости
  __main__.py     # команды scan / build / view
scripts/
  fetch_sample.py # извлечение одной пары из публичного архива Kaggle
tests/            # координаты, ошибочные входы, реальные события viewer
docs/first_run.md  # результаты, проблемы, следующие шаги
data/imagechd/    # исходные NIfTI, XLSX, каталог архива, SHA-256
outputs/ct_1001_v1/
  slices.png
  preview.png
  report.json
  meshes/         # 7 отдельных .vtp
```

`data/`, `outputs/` и `.venv/` исключены из Git. Исходные NIfTI не изменяются. После клонирования результаты создаются командой `build`; иллюстрации и пример JSON опубликованы в `docs/`.

## Установка с нуля

Проверены Python 3.14, Windows, PyVista 0.49.0 и VTK 9.7.0. Примеры используют Windows Python Launcher (`py`). Команды выполняются из каталога клонированного проекта:

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe scripts\fetch_sample.py
.\.venv\Scripts\python.exe -m heart3d scan data\imagechd
.\.venv\Scripts\python.exe -m heart3d build --ct data\imagechd\ct_1001_image.nii.gz --mask data\imagechd\ct_1001_label.nii.gz --out outputs\ct_1001_v1 --preview
.\.venv\Scripts\python.exe -m heart3d view outputs\ct_1001_v1
```

`requirements.txt` содержит диапазоны зависимостей, `requirements-lock.txt` — фактически проверенные версии. GPU и CUDA не требуются; для окна и `--preview` требуется работоспособный рендеринг VTK. Без `--preview` построение mesh и срезов не открывает окно.

`build` требует пустую/новую выходную папку и не перезаписывает предыдущий эксперимент. Если графический драйвер не позволяет сохранить превью, mesh и `report.json` уже сохранены: их можно открыть на машине с поддержкой VTK.

## Файлы ImageCHD

Источник: [Kaggle](https://www.kaggle.com/datasets/xiaoweixumedicalai/imagechd), описание: [репозиторий авторов](https://github.com/XiaoweiXu/ImageCHD-A-3D-Computed-Tomography-Image-Dataset-for-Classification-of-Congenital-Heart-Disease).

На 28.09.2026 Kaggle API перечисляет 13 частей: `ImageCHD_dataset.z01`–`.z12` по 734 003 200 байт и `ImageCHD_dataset.change2zip` на 129 066 047 байт. Общий размер частей — 8 937 104 447 байт. Внутри:

```text
ImageCHD_dataset/
  ct_1001_image.nii.gz
  ct_1001_label.nii.gz
  ...                         # 110 пар, номера не непрерывные
  imagechd_dataset_image_info.xlsx
  imageCHD_dataset_info.xlsx
```

`fetch_sample.py` получает последнюю часть для каталога, затем декодирует только необходимый префикс `.z01`. Это примерно 203 МБ сетевых данных для первого запуска. Проверяет размер и CRC32 исходных записей и сохраняет SHA-256 пары в `provenance.json`. Таблицы извлекаются из последней части без дополнительной загрузки. Скрипт рассчитан на текущую упаковку ImageCHD и выбирает первую целую пару в первом томе; не является универсальным клиентом многотомных ZIP. При смене упаковки останавливается с ошибкой.

Для полного набора скачайте все части, поместите рядом, переименуйте только `.change2zip` в `.zip` и распакуйте `.zip` средствами 7-Zip с поддержкой split ZIP. Если Kaggle выдал внешние ZIP-обёртки для каждой части, сначала извлеките из них оригинальные `.z01`…`.z12` и `.change2zip`. Не распаковывайте тома как независимые архивы. `scan` рекурсивно находит пары по `_image`/`_label`, без предположения о последовательной нумерации.

## Метки

| ID | Код | Структура |
|---:|---|---|
| 0 | — | Фон |
| 1 | LV | Левый желудочек |
| 2 | RV | Правый желудочек |
| 3 | LA | Левое предсердие |
| 4 | RA | Правое предсердие |
| 5 | MYO | Миокард |
| 6 | AO | Аорта |
| 7 | PA | Лёгочная артерия |

Авторы указывают, что в других случаях встречаются дополнительные метки, например 14. Они учитываются в отчёте, но не включаются в сердечные поверхности и цветную разметку. Отсутствующая метка не считается диагнозом.

## Что проверяет прототип

- Трёхмерность, конечность значений, положительный spacing, невырожденность affine, наличие qform/sform и их противоречия.
- Целочисленные неотрицательные метки; пустая и вероятностная маски отклоняются.
- Совпадение сеток после перестановки/отражения осей без интерполяции. Несовпадение размеров или affine останавливает построение. Допуск affine — `1e-4`, без относительного допуска.
- Единицы meter/micron переводятся в mm, unknown сохраняются как unknown. Автоматической подстановки spacing из XLSX нет.
- Срезы в трёх переориентированных плоскостях, по 25/50/75% диапазона размеченного сердца. Для наклонной съёмки это нативные плоскости, не истинные ортогональные MPR. Для shear отчёт предупреждает об ограничении прямоугольного 2D-отображения.
- Marching cubes отдельно для каждой метки, уровень 0.5. Координаты вершин переводятся полной affine: масштаб, поворот, отражение и смещение учитываются один раз. Padding компенсируется в координатах. Нормали согласуются после преобразования.
- Сохраняются все компоненты без сглаживания и упрощения. В отчёте есть компоненты по 26-связности, контакт с границей скана, граничные и неманифолдные рёбра. Отсутствие таких рёбер само по себе не доказывает отсутствие самопересечений.

По умолчанию окно интенсивности определяется 1-м и 99-м процентилями внутри сердечной маски. Можно задать `--window 1000 2000`. Значения не называются HU без подтверждённой калибровки. Цвета срезов и 3D одинаковы.

Вершины VTP содержат координаты; `field_data` хранит ID метки, систему координат и единицы. `report.json` хранит входные хеши, исходные заголовки, affine, количество вокселей, параметры реконструкции, предупреждения и версии библиотек. Объёмы/площади при неизвестных единицах записаны только в условных единицах, не в мл/мм².

Документация методов: [координаты NiBabel](https://nipy.org/nibabel/coordinate_systems.html), [marching cubes](https://scikit-image.org/docs/stable/api/skimage.measure.html#skimage.measure.marching_cubes), [флажки PyVista](https://docs.pyvista.org/api/plotting/_autosummary/pyvista.plotter.add_checkbox_button_widget).

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Тесты используют аналитически проверяемый параллелепипед с анизотропным spacing, перестановкой осей, отражением и смещением, проверяют эквивалентную переориентацию и отклонение неверной сетки. Тест viewer вызывает настоящее событие VTK checkbox, сравнивает изображения до/после, проверяет вращение и zoom. Дополнительно выполнен полный прогон и визуально просмотрены срезы и 3D на реальном `ct_1001`.

В текущей комбинации NumPy 2.5.3 / scikit-image 0.26.0 есть DeprecationWarning о присваивании `array.shape` внутри scikit-image; тесты и реконструкция проходят. Предупреждение не скрыто.
